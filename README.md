# Foxy Treasure Trail

Foxy Treasure Trail is a 2D adventure game developed using Unity. Players control Foxy as they explore different trails, collect treasures, defeat enemies, and overcome obstacles throughout the journey. The game combines exploration, combat, and platforming mechanics in an interactive 2D environment.

---

## Features

- 2D adventure gameplay
- Enemy combat system
- Treasure and collectible system
- Multiple environments and levels
- Obstacles and traps
- Smooth player movement and controls
- Interactive gameplay mechanics

---

## Built With

- Unity Game Engine
- C#
- 2D Sprites and Animations
- Visual Studio
